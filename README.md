TaskFlow – Kanban Task Management Board

TaskFlow is a responsive Kanban Board application built using HTML, CSS, and JavaScript. It helps users organize, manage, and track their daily tasks across three different stages: To Do, In Progress, and Done.

🚀 Features

* Task Management: Add, edit, and delete tasks.
* Three Task Columns: To Do, In Progress, and Done.
* Drag and Drop: Move tasks between columns.
* Priority Levels: Low, Medium, and High.
* Due Dates: Set deadlines for tasks.
* Search Tasks: Quickly find tasks using the search bar.
* Priority Filter: Filter tasks based on priority.
* Local Storage: Automatically save tasks in the browser.
* Dark/Light Mode: Switch between light and dark themes.
* Task Statistics: View total, in-progress, and completed tasks.
* Progress Tracking: Visual progress bar.
* Overdue Highlighting: Identify tasks past their due dates.
* JSON Export and Import: Back up and restore tasks.

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome Icons
* Browser LocalStorage API
